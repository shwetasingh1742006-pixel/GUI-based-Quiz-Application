## GUI-based-Quiz-Application
A desktop-based Quiz Application featuring a clean Tkinter GUI, powered by Python and backend MYSQL database management.

## Features
* Interactive GUI: Built with Python's Tkinter library for a clean and smooth user experience.
* Dynamic Questions: Fetches quiz questions, multiple-choice options, and correct answers directly from a MySQL database.
* Score Tracking: Calculates and displays the final score instantly at the end of the quiz.
* Secure Backend: Uses MySQL to manage question banks, user data, and scores efficiently.

## Tech Stack
* Frontend: Python (Tkinter GUI) 
* Backend: Python
* Database: MySQL

## Files Included
* main_app.py - The main entry point of the application.
* quiz_engine.py - Handles the quiz logic and core processing.
* db.py / auth.py / email_service.py - Core backend modules for database connectivity, authentication, and communication.

* quiz_system_mysql_code.sql - SQL script to set up the database and tables.
